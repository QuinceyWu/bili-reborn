## 这是什么

一个跑在浏览器里的 B 站账号清理工具。

你有没有过这种时候：翻自己的空间，发现几年前转发的一堆东西；关注列表里躺着几百个已经想不起来为什么要关注的人；评论区里还留着一些现在看会尴尬的发言。

B 站没有提供批量清理的功能，只能一条一条点。这个脚本就是把这件事自动化。

它不联网上传任何东西，不碰你的密码。所有请求都从你自己的浏览器、用你自己的登录态发出去，和你手动点击没有本质区别 —— 只是快很多，而且会刻意慢下来，避免被风控盯上。

## 功能

**批量删除动态**

扫描空间里的全部动态并逐条删除。先完整扫描再统一删除，避免边删边翻页导致的漏删。置顶动态自动跳过。

**批量取消关注**

拉取完整关注列表后逐个取关。可以填 UID 白名单，名单里的人不会被碰。

**批量清理评论**

B 站没有「我的评论」列表，所以从消息中心的「收到的回复」反查你评论过的楼层，再逐层定位属于你的评论。也可以手动粘贴 BV 号指定范围。

**防封号**

随机延迟、批次休息、指数退避、熔断冷却四层机制，外加每日配额。细节见 [防风控设计](docs/RISK-CONTROL.md)。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 打开 [Releases](https://github.com/QuinceyWu/bili-reborn/releases/latest)，点 `bili-reborn.user.js` 安装

   或者复制 [bili-wiper.user.js](tampermonkey/bili-wiper.user.js) 全文，在 Tampermonkey 里新建脚本粘贴进去

3. 打开 [bilibili.com](https://www.bilibili.com)，右下角会出现粉色的悬浮球

## 第一次用，按这个顺序

**① 先跑一次接口自检**

打开面板 → 设置 → 接口自检。它会只读探测三个关键接口，几秒钟告诉你当前账号能不能正常调用。

三项都显示「正常」再往下走。如果动态项报 412，说明你的网络出口被 WAF 拦了，换个时间或换个网络再试。

**② 保持演练模式，先跑一遍**

设置里的「演练模式」默认是开的。它会完整走一遍扫描流程，打印出「将删除多少条」，但不会真的删。

对着数量核对一下，确认没算错。

**③ 关掉演练模式，正式跑**

建议一次只跑一项，别三个一起上。

## 它安全吗

**不会上传你的数据。** 脚本没有任何上报逻辑，所有请求直达 `api.bilibili.com`。

**不会碰别人的数据。** 删除接口都带身份校验，只能删自己的。评论清理还会额外比对 `member.mid` 是不是你自己。

**不会失控。** 随时可以暂停或停止，停止是软停止 —— 当前这一条请求会正常收尾，不会留下半截状态。每日配额默认 100 条，防止挂机过夜。

**但也不是零风险。** 任何自动化都低于官方客户端的容忍度。用稳健参数、分几天完成，比一次跑完更安全。

## 已知限制

**动态**：视频投稿和专栏类动态通过 `rm_dynamic` 删不掉（它们本质是稿件），需要在创作中心处理。脚本会跳过并记录。

**评论**：只能清理「有人回复过你」的楼层。如果你在某条视频下评论过但没人回复，消息中心里没有记录，脚本找不到。这种情况可以手动粘贴 BV 号指定范围。

**关注**：没有按条件筛选的能力，只能全量取关 + 白名单。想保留一批人的话，得先把 UID 填进白名单。

## 常见问题

**删到一半停了，会重复删吗？**

不会。已经删掉的不会出现在后续列表里，重跑时自然跳过。

**提示 412 怎么办？**

触发了风控。脚本会自己退避重试，连续 3 次会进入 15~30 分钟冷却。等冷却结束，或者把设置里的延迟调大到 3000~6000ms 再试。

**会不会封号？**

只做删除自己的数据，请求频率被压到接近人工。但任何自动化都有风险，请用稳健参数、分多次完成。

**评论清理很慢？**

正常。每个楼层都要单独请求一次，这是接口能力上限，不是实现问题。
